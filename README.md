# Vallore Shopify theme package

Upload the CONTENTS of this folder into the GitHub repository root. The ZIP has no enclosing folder.

## Preserved version
Gallery: Product, Strawberry lemonade, Daily ritual, Benefits, Ingredients.
Product is selected initially. Original review and section photographs are preserved.
Review labels: 1,200 reviews; Iris W, Jennifer P, Karen V.
CSS, JavaScript, text, responsive styles and original page interactions are retained.

## Installation
1. Extract the ZIP and upload all files and directories to the repository root.
2. Connect the repository/branch through Shopify's theme GitHub integration, or upload the ZIP as a theme.
3. Preview the theme before publishing. The homepage shows the original home view; product templates show the product view.

## Scope and launch requirements
This is a conversion of the supplied static storefront, not a fully wired commerce implementation.
Original prices, purchase controls, bundle choices, and subscription interactions remain static. They are NOT bound to Shopify variant IDs, selling plans, product inventory, or live pricing. Configure actual products and implement cart/subscription integration before taking orders.
A basic Shopify cart template is included; the original storefront purchase buttons are not connected to it.
No collection/search/customer templates have been implemented.
The storefront is provided as one section to preserve layout, not as independently configurable section blocks.
Verify review count, reviewer identity, verified-buyer labels, testimonials, and health claims before publication.
The package has been structurally checked locally, not deployed or tested in Shopify or a browser.
Google Fonts remains an external dependency, as in the original HTML.
